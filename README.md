# Task Management Application

A simple and responsive **Task Management Application** that allows users to register, log in, and manage their daily tasks efficiently.

## 🚀 Features

* 🔐 User Registration and Login
* 👤 User Authentication
* ➕ Create new tasks
* ✏️ Update existing tasks
* 🗑️ Delete tasks
* 📋 View and track tasks
* 📱 Responsive user interface
* 💾 SQLite database integration
* ⚙️ Backend API using Node.js and Express.js

## 🛠️ Technologies Used

### Frontend

### Backend

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/trishikark135-rgb/Task-Management-App.git
```

### 2. Open the Project

```bash
cd Task-Management-App
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Server

```bash
node server.js
```

The backend server will run on:

```text
http://localhost:5000
```

### 5. Open the Application

Open `login.html` or `index.html` using Live Server in VS Code.

## 🔑 How to Use

1. Register a new account.
2. Log in using your registered credentials.
3. Add a new task.
4. View your tasks.
5. Update tasks whenever required.
6. Delete completed or unnecessary tasks.
